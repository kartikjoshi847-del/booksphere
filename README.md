# 📚 BookSphere

BookSphere is an Android application built using **Kotlin** and **Android Studio**. It helps users discover, search, and explore books through a simple and user-friendly interface.

## ✨ Features

- 🔐 User Login & Registration
- 📖 Browse Books
- 🔍 Search Books
- 📚 View Book Details
- ❤️ Save Favorite Books
- 👤 User Profile

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- XML
- Git
- GitHub

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/kartikjoshi847-del/Booksphere.git
```

2. Open the project in Android Studio.

3. Let Gradle sync.

4. Run the app on an Android emulator or a physical device.
