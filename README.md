## 📖 About

BookSphere is an Android application developed using **Kotlin** and **Android Studio**. It provides users with a simple and intuitive platform to discover, search, and manage books.

The application is designed with a clean and modern user interface, making it easy for readers to explore books and organize their reading experience.

---

## ✨ Features

- 🔐 User Login & Registration
- 📚 Browse Books
- 🔍 Search Books
- 📖 View Book Details
- ❤️ Save Favorite Books
- 👤 User Profile
- 📱 Clean & User-Friendly Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/kartikjoshi847-del/Booksphere.git
```

### Open in Android Studio

1. Open Android Studio.
2. Click **Open Existing Project**.
3. Select the **Booksphere** folder.
4. Allow Gradle to sync.
5. Run the application.
